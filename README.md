A Wi-Fi name is the shortest story a stranger ever reads: it hangs in a
phone's network list with no setup and no second chapter. This entry
squeezes a whole divorce into twenty-five characters — a man leaves, and
the one thing he carries out the door says everything about him.

The saved line reads `HeTookTheRouterNotTheKids`: twenty-five characters,
one packing decision, the children left behind while the router went with
him. Setup, character and punchline, all inside a network name.

## Why the ending works

The first draft stopped at him walking out, which only reports that a
split happened. The revision keeps the walkout and swaps what it lands
on: of everything he could carry, he chose the router over his own
children. That absurd priority is the joke, and nobody needs backstory
to get it.

## Running it

```sh
python3 main.py
```

## How the winner is picked

Twelve invented names are each given four marks out of ten — punch,
plot, novelty and snap — and every one of them stays under the
thirty-two character cap. The highest total wins; a draw goes to the
shorter name, so the result never changes between runs. A second look
then sharpens the winner's ending before anything is written, and the
file is read back and hashed to catch a short write.
